# 鸣潮入场动画

为 DeepSeek Harness（DSH）提供 20 个可选角色的静音开场动画，包含线稿入场、完整/快速播放和粒子退场。视频为 **3840×1488、60 fps**：保留 4K 素材的横向像素，裁去上下无效区域，按原比例显示。

![守岸人动画预览](assets/characters/shorekeeper.webp)

当前版本 **0.4.8**。DSH 版本声明为 **`>=0.2.2-rc.1 <0.3.0-0`**，需要 Node.js 24 或更新版本。DSH 桌面端使用自带运行时。历史播放回归见下文。

0.4.3 于 2026-11-12 完成兼容性验证：37 项自动回归通过；两个桌面版本各完成 20 个角色 × 完整/快速两种模式，共 80 次播放，均正常结束且释放 Blob，视频解码尺寸均为 3840×1488，150% 缩放下画布尺寸全部匹配设备像素比。每个桌面版本的 40 次播放累计记录到 8 帧丢帧。两个版本均验证了重启自动开场、刷新不重复播放和偏好保留；rc.1 另通过真实设置界面的角色选择核验。内置浏览器的正常注入、客户端补载及模拟媒体错误回退共 8 次播放通过，未记录到丢帧。版本范围的 9 个边界样例只验证声明解析，不代表未来宿主实测。0.4.4 整理公开发布信息、安装脚本和制作脚本，沿用同一套播放逻辑及 20 个角色素材。

完全退出并重新打开 DSH，开场先绘制所选角色的声痕线稿，再按完整画幅居中播放视频，最后采样视频画面生成粒子并淡出到工作台。上下留白足够时，环形光迹、对称波纹和进度亮点沿用各角色的配色；波纹振幅和光环亮度随当前视频画面的运动强度变化。点击画面或按 Esc 可立即跳过。动画静音播放；系统启用减少动态效果时跳过线稿与退场特效，关闭波纹起伏，保留原视频。

打开「设置 → 鸣潮入场动画」选择角色。所选角色会在下次启动时生效，也可点击「预览所选角色」立即播放。默认角色是守岸人，可在同一页关闭「启动时播放」。

播放模式默认「完整播放」，旧版偏好自动沿用。可切换到「快速开场」，播放人工逐角色挑选的最多 2 秒片段，前后特效各 0.45 秒，总计约 2.1～2.9 秒。设置页显示的预计总时长包含线稿和退场，不含加载等待。

两种模式各有一套与播放起点对应的线稿，设置页预览图保持独立。完整模式跳过最多 0.4 秒的片头低细节过渡，从可辨识画面开始播放；MP4 素材文件没有裁改。视频定位和线稿准备并行进行，首帧回调到达后再切换画面；无帧回调支持时按播放事件降级。

启动动画开始后隐藏窗口会自动结束。手动预览隐藏时暂停视频、特效和全部超时计时，恢复可见后继续。线稿请求超过 250 毫秒、数据损坏或 Canvas 绘制异常时直接播放视频；粒子采样失败时使用简单淡出。每种媒体载入方式最多等待 4.5 秒，失败或无法定位时可切换另一种方式一次；开始播放后不重新载入，整个流程另有总时限保护。

## 安装

### 使用固定仓库地址

在 DSH「插件 → 添加插件」的顶部输入框粘贴以下仓库地址，安装完成后启用插件。

```text
https://github.com/kun111-web/dsh-wuthering-waves-intro
```

DSH 从默认分支 `main` 的当前提交安装，仓库内已包含全部 20 个角色的视频和预览图。安装后会锁定该提交。升级时，从托盘完全退出 Windows 版 DSH，再用桌面端提供的 `dsh` 命令重新安装同一个地址。打开 DSH 后可在插件详情核对版本。

```powershell
dsh plugin --profile desktop add 'https://github.com/kun111-web/dsh-wuthering-waves-intro'
```

### 使用 Release 安装包

在「添加插件」顶部填写 `.tgz` 的完整本地路径，或粘贴附件下载地址。需要离线安装时，可提前下载。[最新 GitHub Release](https://github.com/kun111-web/dsh-wuthering-waves-intro/releases/latest)

```text
https://github.com/kun111-web/dsh-wuthering-waves-intro/releases/download/dsh-wuthering-waves-intro-v0.4.8/dsh-wuthering-waves-intro-0.4.8.tgz
```

或者使用 CLI 安装到桌面配置：

```powershell
dsh plugin --profile desktop add 'C:\Downloads\dsh-wuthering-waves-intro-0.4.8.tgz'
```

安装包约 289 MiB，内含全部 20 个视频和预览图，可以下载后离线安装。校验值见 Release 附件 `SHA256SUMS.txt`，可用 PowerShell 核对：

```powershell
Get-FileHash 'C:\Downloads\dsh-wuthering-waves-intro-0.4.8.tgz' -Algorithm SHA256
```

将示例路径替换为实际下载位置。安装后完全退出并重启 DSH，再到「设置 → 鸣潮入场动画」选择角色。卸载可在 DSH 插件列表操作。

### 本地开发

从本地源码验证时，先运行 `npm run pack:plugin` 生成安装包，再运行 `./install.ps1`。脚本从 PATH 查找 `dsh`，也可使用 `./install.ps1 -DshCommand '<DSH CLI 完整路径>'`。脚本从本项目 `dist/` 安装并核对依赖来源及版本。公开安装包统一发到本仓库的 GitHub Releases。

## 数据与权限

播放时通过 DSH 本地资源路由读取安装包内的媒体、线稿和样式。不需要 API Key，播放时不调用外部服务。角色、播放模式和启动偏好保存在 WebView 的本地存储中。不读取或上传聊天内容，不修改 DSH 主程序。单次只载入所选角色视频，结束、跳过和卸载时释放临时 Blob 地址。

## 素材与许可

动画素材：鸣潮角色声痕动画。鸣潮相关素材归库洛游戏及相关权利人所有，包括本插件使用的视频、预览图、由画面提取的线稿及角色形象等。插件原创代码继续采用 Apache-2.0；上述素材不属于该代码许可证的授权范围，详见 [NOTICE.md](NOTICE.md)。本项目为第三方插件，不代表鸣潮、库洛游戏或 DeepSeek 官方。

0.4.3 的兼容性修改不重新编码或替换素材，20 个视频和预览图沿用 0.4.2。偏好存储名称保持不变。DSH 跨发行系列升级后，应检查自动开场、完整/快速播放、设置保存、跳过和清晰度后再扩大版本声明，不使用兼容性豁免强行加载。

0.4.2 清除夏空片段的中英字幕、露帕结尾与忌炎开头转场带入的字幕残影，以及莫宁画面的小字；预览图、完整和快速线稿同步重新生成。仅修补文字所在区域，保持 3840×1488、60 帧/秒和原片段帧数。20 个视频均只含 H.264 视频轨，无音频、字幕或数据轨。`scripts/media-cleanup.json` 记录修补区域及时间范围；`npm run clean:media` 用于处理现有角色片段，已处理且哈希一致的文件不会重复编码。`npm run split` 已集成相同规则，避免重新分割时带回字幕。

从 3840×2160、60 帧/秒素材切出 20 个独立的 MP4，每个片段保留 3840×1488 的有效画面及 60 帧/秒，使用 H.264 编码。设置页预览图为 768×298，未使用 AI 超分辨率。帧区间见 `src/characters.json`；安装包不包含原合集、中间下载文件或 QA 产物。重新分割前需要自行提供与角色时间轴匹配的原始素材；默认路径为 `assets/source-2160p.mp4`，也可通过 `npm run split -- '<完整路径>'` 指定。

0.4.1 修复桌面端首次加载时完整模式卡在线稿后超时退出的问题。DSH 自定义协议的流式响应可能将视频可定位范围报告为 0；桌面端现在并行读取当前角色的视频和线稿，用临时 Blob 地址提供完整可定位的原视频。仅持有所选角色的一个片段，不重编码或降低分辨率，结束、跳过、替换和加载失败时取消请求并释放地址。普通浏览器继续使用流式媒体地址。自动测试补充桌面加载、定位、取消竞态和内存地址释放的回归检查。

0.4.0 使用 4K/60 帧素材，线稿按 3840×1488 画面提取，画布按实际显示宽度乘设备像素比绘制，最高 3840×1488；窗口大小及 DPI 改变时重新绘制，线宽保持约 1 个 CSS 像素。Canvas 以最高约 60 次/秒绘制，高刷新率屏幕不再重复绘制同一进度。视频首选逐帧回调，超过 500 毫秒无回调时由播放事件接管。

同一宿主运行会话只自动播放一次，页面刷新和重连不重播；完全退出并重启宿主后可再次播放。标记在窗口首次可见时写入，隐藏窗口不会提前消耗机会。此去重依赖本地存储；本地存储不可用时只在当前页面内去重。手动预览不受限制。

资源 URL 携带版本号，支持 ETag 校验和浏览器持久缓存；不带版本的旧地址仍可用但每次需校验。解析过的线稿使用最多 8 项的 LRU 缓存，失败或已取消的请求不会缓存。`scripts/quick-scenes.json` 保存人工挑选的快速片段及理由，帧号沿用 30 Hz 剪辑时间轴（实际 60 fps 视频中的帧号为其两倍）；重新运行 `npm run trace` 保留人工选择，未知角色或越界配置会报错。
